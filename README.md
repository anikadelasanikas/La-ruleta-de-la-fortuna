Juego de ruleta interactivo hecho con Python y la librería Turtle.
Como funciona:
- Aparece una ruleta roja en la pantalla.
- El jugador hace clic en la ruleta para girarla.
- Se genera un número aleatorio del 1 al 100.
- Según el número, el jugador gana un premio (¡o no!).

Como jugar:
1. Ejecuta el archivo `Ruleta de la fortuna.py`
2. Haz clic sobre la ruleta roja
3. ¡A ver qué premio te toca!

Premios:
- Número 1-10 → Has perdido
- 11-20 → Un pez
- 21-45 → Un peluche (con su "peculiaridad" de fábrica)
- 46-70 → Un premio sorpresa
- 71-100 → Un viaje a mi cerro 

Que aprendi:
- La librería Turtle para dibujar y crear la interfaz gráfica
- La librería random para generar números aleatorios
- Funciones (def)
- Condicionales (if / elif / else) 
- Manejo de eventos (onclick) para que el juego reaccione al clic

Como ejecutarlo
- Necesitas Python 3 con la librería Turtle (viene incluida).
- Ejecuta en la terminal:
- Python "Ruleta de la fortuna.py"
